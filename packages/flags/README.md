# @zedtech/zedkit-flags

> **Lab experiment:** this package is a workbench, not a shelf product — don't use it in production. Steal the code if it's useful; that's the point. [Read the story behind zedkit](https://medium.com/p/ce86bfc96636).

Thin helpers around [OpenFeature](https://openfeature.dev/) for typed registries, in-memory and JSON providers, server `getFlag`, React `useFlag`, and `localStorage` overrides for local dev.

See [CATALOG.md](./CATALOG.md) for exports and examples.
